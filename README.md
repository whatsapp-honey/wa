# Landing page

## Struktur
- `index.html` — halaman utama, terjemahan otomatis, tombol redirect, dan metadata preview sosial.
- `images/1.jpg` — background doodle.
- `images/3.png` — logo transparan di bagian atas.
- `images/2.jpg` — gambar WhatsApp di tengah.

## Terbitkan di GitHub Pages
Upload seluruh isi folder ini ke root repository, lalu aktifkan Settings → Pages → Deploy from a branch → main → /(root).

## Penting untuk preview Threads/X
Di `index.html`, ganti `YOUR-GITHUB-USERNAME` dan `YOUR-REPOSITORY` pada nilai `og:image` dan `twitter:image` dengan alamat GitHub Pages yang sebenarnya. Preview gambar hanya dapat dibaca setelah website dipublikasikan dengan URL HTTPS publik. Platform sosial dapat menyimpan cache preview.

## Copy deterrents and limits
The page blocks common right-click, drag, text-selection, and keyboard shortcuts (F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S) as a casual deterrent. This cannot prevent copying: visitors can still use browser menus, developer tools, network requests, screenshots, or retrieve public image/HTML files. GitHub Pages serves static files publicly; do not put secrets or private credentials in this page.
